Geospatial Chicago Crash Analysis

Problem

Visualize high congestion/problematic zones within Chicago using crash data.

Data

Publicly available Chicago traffic crash dataset via Chicago Data Portal.

Methods

Crash location data for Chicago was analyzed using spatial analysis techniques with GeoPandas and Shapely. Circular buffers were generated around each crash point using a fixed Euclidean distance of the average Chicago block to model localized impact zones. Overlapping buffer regions were then identified using spatial intersection methods to detect areas of concentrated crash activity via heatmap.

Additionally, heatmaps were used to visualize if there any unique loci of crash density throughout a day in Chicago. 


  def similarityAnalysis(stripesRDD, n):
      """
      This function defines a Spark DAG to compute cosine, jaccard, 
      overlap and dice scores for each pair of words in the stripes
      provided. 
      
      Output: an RDD, a list of top n, a list of bottom n
      """
      simScoresRDD, top_n, bottom_n = None, None, None
      
      ############### YOUR CODE HERE ################
      #stripe lentgths
      stripe_lengths = stripesRDD.mapValues(lambda co_words: len(co_words))
  
      #merge to rdd
      stripes_with_length = stripesRDD.join(stripe_lengths)
      
      #posting creation
      postings = stripes_with_length.flatMap(
          lambda x: [(co_word, (x[0], x[1][1])) for co_word in x[1][0]]
      )
  
      #invert index
      inv_index = postings.aggregateByKey(
          set(),
          lambda s, v: s | {v},
          lambda s1, s2: s1 | s2
      )
  
      #pair cooccur
      cooccurr = inv_index.flatMap(lambda x: [
          ((min(t1, t2), max(t1, t2)), 1)
          for t1 in x[1] for t2 in x[1] if t1[0] < t2[0]
      ]).reduceByKey(lambda a, b: a + b)
      
      #similarity scores
      simScores = cooccurr.map(lambda x: (
          f"{x[0][0][0]}, {x[0][1][0]}",
          {
              'intersection': x[1],
              'length1': x[0][0][1],
              'length2': x[0][1][1]
          }
      )).mapValues(lambda d: {
          'cosine': d['intersection'] / ((d['length1'] * d['length2']) ** 0.5) if d['length1'] and d['length2'] else 0,
          'jaccard': d['intersection'] / (d['length1'] + d['length2'] - d['intersection']) if (d['length1'] + d['length2'] - d['intersection']) else 0,
          'dice': 2 * d['intersection'] / (d['length1'] + d['length2']) if (d['length1'] + d['length2']) else 0,
          'overlap': d['intersection'] / min(d['length1'], d['length2']) if min(d['length1'], d['length2']) else 0
      })
  
      #sorting
      top_n = simScores.takeOrdered(n, key=lambda x: -x[1]['cosine'])
      bottom_n = simScores.takeOrdered(n, key=lambda x: x[1]['cosine'])
  
      # display
      top_n = [(pair, [score['cosine'], score['jaccard'], score['overlap'], score['dice']]) for pair, score in top_n]
      bottom_n = [(pair, [score['cosine'], score['jaccard'], score['overlap'], score['dice']]) for pair, score in bottom_n]
  
      # clean output format to work with display
      result = simScores.mapValues(lambda d: [d['cosine'], d['jaccard'], d['overlap'], d['dice']])
  
      
  
      #output
      return result, top_n, bottom_n

Results

Impact

Identifies high-density crash zones in Chicago, often correlated with high foot traffic areas such as clustered shopping centers or structural road design issues such as 90° turns or six lane intersection.

Time-dependent heatmaps of Chicago showcased the expected density of accidents around downtown especially during communting hours (7-10am, 3-6pm) and socializing hours (8pm-11pm) but does not elucidate any new loci of crash density that changes thoughout the day.
