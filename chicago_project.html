Project Case Study

Geospatial Chicago Crash Analysis

Problem

Visualize high congestion/problematic spheres of influences within Chicago

Data

Publically available Chicago dataset

Methods

Crash location data for Chicago was analyzed using spatial analysis techniques with GeoPandas and Shapely. Circular buffers were generated around each crash point using a fixed Euclidean distance of the average Chicago block to model localized impact zones. Overlapping buffer regions were then identified using spatial intersection methods to detect areas of concentrated crash activity. These overlapping regions were interpreted as high-risk zones, providing a proxy for spatial clustering of incidents. The approach approximates density-based clustering through geometric proximity rather than probabilistic estimation.

Results

Impact

Helps determine high density crash sites within Chicago, which were determined to be high foot traffic areas or structural anomalies such as a near 90 degree turn.
