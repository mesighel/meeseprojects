Geospatial Chicago Crash Analysis

Problem

Visualize high congestion/problematic zones within Chicago using crash data.

Data

Publicly available Chicago traffic crash dataset via Chicago Data Portal.

Methods

Crash location data for Chicago was analyzed using spatial analysis techniques with GeoPandas and Shapely. Circular buffers were generated around each crash point using a fixed Euclidean distance of the average Chicago block to model localized impact zones. Overlapping buffer regions were then identified using spatial intersection methods to detect areas of concentrated crash activity.

Results

Impact

Identifies high-density crash zones in Chicago, often correlated with high foot traffic areas such as clustered shopping centers or structural road design issues such as 90° turns or six lane intersection.
